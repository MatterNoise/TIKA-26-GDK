# TIKA-26 GDK

## About
The TIKA-26-GDK Library (or simply TIKA-26) is a **Free** and **Open** Game Developing Kit for [**TIC80**](https://github.com/nesbox/TIC-80) aimed to be simple and easy to code

With Built-in functions like Vector manipulation, Drawing operations, Sound system tool and more!, you can create your own programs and games around the TIC-80 ecosystem more fast and easy
